\section{Overview}

The AI image generation pipeline is an autonomous system that accepts a
natural language prompt and iteratively generates, scores, and refines
images until a candidate meeting all quality thresholds is accepted by a
tactical large language model (LLM).

The pipeline is designed around three principles:

\begin{enumerate}
  \item \textbf{Observable}: every message, score, and verdict flows through
        inspectable queues and exchanges. RabbitMQ's management interface
        provides real-time visibility into all message flows.
  \item \textbf{Scalable}: each component is independently deployable. The
        message broker provides natural decoupling. Adding scorer capacity
        requires only adding subscriber processes.
  \item \textbf{Persistent}: every generated image is recorded in LanceDB as
        a vector embedding alongside full scorer results and generation
        parameters. This long-term memory enables the strategic LLM to
        identify patterns across sessions.
\end{enumerate}

\section{Component Architecture}

\subsection{Language Selection}

Two components are implemented in Rust rather than Python:

\begin{description}
  \item[Router] Zero business logic, no ML dependencies. A compiled binary
        with negligible memory footprint ($\sim$5\,MB) is appropriate for
        pure message routing.
  \item[Aggregator] Manages concurrent state across multiple incoming message
        streams. Rust's ownership model prevents data races at compile time.
\end{description}

All components with ML model dependencies are Python.

\section{Data Flow}

\begin{enumerate}
  \item Tactical LLM publishes to \texttt{loop.request}.
  \item \texttt{comfyui\_worker} submits workflow to ComfyUI, awaits WebSocket completion.
  \item On completion, publishes to \texttt{loop.events} with routing key \texttt{loop.complete.<uuid>}.
  \item Rust \texttt{router} fans out to \texttt{scorer.requests} with routing key \texttt{score.<uuid>}.
  \item All three scorers receive the message simultaneously and begin scoring in parallel.
  \item As results arrive, the Rust \texttt{aggregator} accumulates them in Redis (\texttt{agg:session:<uuid>}, TTL 60s).
  \item Threshold evaluation on each arrival:
    \begin{itemize}
      \item CLIP score below threshold: \texttt{GETDEL}, publish cancel, emit rejected verdict.
      \item Artifact confidence above threshold: same cancel and reject flow.
      \item All three results within bounds: \texttt{GETDEL}, emit candidate verdict.
    \end{itemize}
  \item \texttt{lancedb\_manager} independently accumulates scorer results in Redis (\texttt{ldb:session:<uuid>}, TTL 120s).
        Writes to LanceDB on cancel (rejected) or \texttt{loop.accepted} (candidate) events.
\end{enumerate}

\section{Threshold Calibration}

\begin{center}
\begin{tabular}{lll}
\toprule
\textbf{Threshold} & \textbf{Value} & \textbf{Semantics} \\
\midrule
\texttt{CLIP\_THRESHOLD} & 0.25 & Reject if CLIP score $< 0.25$ \\
\texttt{ARTIFACT\_THRESHOLD} & 0.50 & Reject if AI confidence $> 0.50$ \\
\bottomrule
\end{tabular}
\end{center}

Both values are placeholders. Calibration procedure:

\begin{enumerate}
  \item Run the loop permissively (\texttt{CLIP\_THRESHOLD = 0.0}, \texttt{ARTIFACT\_THRESHOLD = 1.0}).
  \item Query the \texttt{loop} table and examine score distributions.
  \item Set \texttt{CLIP\_THRESHOLD} at the point below which VLM scores are consistently poor.
  \item Set \texttt{ARTIFACT\_THRESHOLD} at the point above which photorealism scores are consistently poor.
  \item Iterate: thresholds too aggressive waste good candidates; too permissive waste VLM compute.
\end{enumerate}

\section{Scale-Out Path}

\begin{description}
  \item[Multiple ComfyUI workers] Add consumers on \texttt{loop.request}.
  \item[Multiple scorer instances] Add subscribers on scorer request queues.
  \item[Remote scoring nodes] Change RabbitMQ connection string.
  \item[Managed broker] Migrate to Amazon MQ (AMQP 0-9-1 compatible).
  \item[Distributed Redis] Migrate to Amazon ElastiCache.
  \item[Cloud LanceDB] Change connection path to S3 URI.
\end{description}
